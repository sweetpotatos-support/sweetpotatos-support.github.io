# Lenumori 개인정보처리방침

시행일: 2026-10-15

Lenumori(이하 "앱")는 사용자의 개인정보와 사진을 중요하게 생각합니다.
본 개인정보처리방침은 Lenumori가 어떤 정보에 접근하고, 해당 정보를 어떤 목적으로 사용하며,
어떻게 보호하는지 설명합니다.

## 1. 기본 원칙

Lenumori는 기본적으로 Offline First 방식으로 동작하도록 설계합니다.

앱의 핵심 기능인 사진·영상 촬영, 필터 적용, 사진 정리, 태그 저장 및 검색은
가능한 범위에서 사용자의 기기 내부에서 처리합니다.

앱은 사용자의 사진을 Lenumori 운영자의 서버에 업로드하거나 저장하지 않는 것을 기본 원칙으로 합니다.

앱은 무료로 제공되며, 광고(Google AdMob)를 보여 줍니다.
광고를 위해 Google 이 기기 정보와 광고 ID 등을 수집할 수 있으며, 사진·영상·태그는 광고에 사용되지 않고 기기 밖으로 전송되지 않습니다.
프리미엄을 구매하면 광고가 표시되지 않습니다.

## 2. 앱이 접근할 수 있는 정보

### 카메라

용도:
- 사진 촬영
- 영상 녹화
- 카메라 미리보기
- 전면/후면 카메라 전환
- 플래시 및 줌 기능

카메라 접근은 사용자가 사진을 촬영하거나 영상을 녹화할 때 필요한 기능 제공을 위해 사용됩니다.

### 마이크

용도:
- 영상을 녹화할 때 소리를 함께 녹음

마이크는 사용자가 촬영 화면에서 셔터를 길게 눌러 영상을 녹화하는 동안에만 사용됩니다.
녹음된 소리는 영상 파일 안에만 저장되며 기기 밖으로 전송되지 않습니다.
마이크 권한을 허용하지 않아도 사진 촬영과 소리 없는 영상 녹화는 그대로 사용할 수 있습니다.

### 사진 및 미디어

용도:
- Lenumori로 촬영한 사진·영상 저장
- 앱 내부 사진·영상 목록 표시
- Lenumori로 촬영한 사진·영상 표시, 재생 및 정리
- 사진에 태그를 연결하여 검색 기능 제공
- 사용자가 요청한 경우 Lenumori로 촬영한 사진·영상 삭제
- 사용자가 요청한 경우 사진·영상 공유

Lenumori는 필요한 범위를 넘어 사용자의 사진에 접근하지 않도록 설계합니다.
Android 10 이상에서는 사진 접근 권한을 요청하지 않으며, Lenumori로 촬영한 사진·영상만 저장·관리합니다.
Android 9 이하에서는 사진·영상을 사진 폴더에 저장하기 위해 저장공간 쓰기 권한을 요청합니다.
영상은 AI 분석을 하지 않습니다.

### 온디바이스 AI 분석 정보

지원되는 기기에서는 사진 내용을 분석하여 다음과 같은 태그를 생성할 수 있습니다.

예:
- 고양이
- 바다
- 노을
- 음식
- 여행

이 분석은 Google ML Kit(이미지 라벨링, GenAI 이미지 설명·Gemini Nano)를 이용해 기기 내부에서 처리합니다.
분석에 사용하는 사진은 기기 밖으로 전송되지 않습니다.

생성된 태그 및 분석 결과는 기본적으로 사용자의 기기 내부에 저장됩니다.

지원하지 않는 기기에서는 AI 태그 기능만 사용할 수 없으며, 사진 촬영·저장·정리 기능은 그대로 사용할 수 있습니다.
AI 모델이 기기에 없는 경우 Android 시스템(AICore)이 Google 로부터 AI 모델을 내려받을 수 있습니다.

앱 언어가 한국어일 때는 AI가 만든 영어 사진 설명을 Google ML Kit 번역을 이용해 기기 안에서 한국어로 번역합니다.
번역에 필요한 언어 모델(약 30MB)은 처음 한 번 Google 로부터 내려받으며, 번역할 문장은 기기 밖으로 전송되지 않습니다.
앱 언어가 영어일 때는 번역하지 않으며 번역 모델도 내려받지 않습니다.

## 3. 외부 서버 전송

현재 Lenumori의 기본 설계에서는 다음 데이터를 Lenumori 운영자의 외부 서버로 전송하지 않습니다.

- 촬영한 사진·영상 (녹음된 소리 포함)
- 사용자의 갤러리 사진
- AI가 생성한 사진 태그
- 사진 검색 기록

### 사용자가 직접 하는 사진 공유

사용자가 사진 상세 화면에서 '공유하기'를 누르면 Android 공유 창이 열립니다.
사진·영상은 사용자가 공유 창에서 직접 고른 앱으로만 전달되며,
Lenumori가 스스로 사진을 외부 서버나 다른 곳으로 보내지 않습니다.
공유된 이후의 처리는 사용자가 고른 앱의 개인정보처리방침을 따릅니다.

### Google ML Kit 사용 통계

기기 내 AI 분석에 사용하는 Google ML Kit 는 기능 개선과 문제 진단을 위해
다음과 같은 사용 정보를 Google 로 전송합니다 (HTTPS 암호화 전송).

- 기기 정보: 제조사, 모델, OS 버전, AI 가속 하드웨어 정보
- 앱 정보: 앱 패키지 이름, 앱 버전
- 앱 설치별 식별자 (사용자 개인을 식별하는 용도가 아님)
- 성능 정보: 처리 시간, 오류 코드, 입력·출력 크기 등 API 사용 정보

이 정보에는 사진, 사진 설명 결과(번역 포함), 태그가 포함되지 않습니다.
자세한 내용은 Google 의 ML Kit 데이터 공개 안내(https://developers.google.com/ml-kit/android-data-disclosure)를 따릅니다.

### 광고 (Google AdMob)

앱은 보관함·사진 상세 화면 아래의 배너 광고와, 사용자가 원할 때 보는 보상형 광고(잠긴 필터를 24시간 사용)를 보여 줍니다.
광고는 Google 의 Google Mobile Ads SDK 가 제공하며, 광고 제공·광고 성과 측정·부정 클릭 방지·(동의한 경우) 맞춤 광고를 위해
다음 정보를 Google 및 Google 의 광고 파트너가 수집·처리할 수 있습니다.

- 광고 ID (Android 광고 ID), 앱 세트 ID (같은 개발자의 앱을 구분하는 기기별 ID)
- 기기 정보: 제조사, 모델, OS 버전, 화면 크기, 언어
- IP 주소 및 이를 통해 추정한 대략적인 위치 (정확한 위치·GPS 는 사용하지 않음)
- 앱·광고 이용 정보: 앱 실행, 화면 탭, 광고 노출·클릭, 보상형 광고 시청 여부
- 앱 정보와 진단 정보: 앱 이름·버전, 앱 실행 시간 같은 성능 정보, 오류 정보

이 정보에는 사진, 영상, 녹음된 소리, 태그, AI 분석 결과가 포함되지 않습니다.
Google 의 데이터 사용 방식은 https://policies.google.com/technologies/partner-sites 를 따릅니다.

맞춤형 광고(행태정보) 안내:
- 맞춤 광고를 위해 광고 ID 와 앱·광고 이용 정보(행태정보)가 Google 에 제공될 수 있습니다.
- 맞춤 광고를 원하지 않으면 휴대폰 설정 > Google > 광고에서 광고 ID 를 삭제하거나 재설정할 수 있습니다.
- 유럽 경제 지역(EEA)·영국 등 동의가 필요한 지역에서는 앱이 처음 광고를 준비할 때 동의 창을 보여 주며,
  앱 '설정 > 광고 개인정보 설정' 에서 언제든 동의를 바꿀 수 있습니다.
- 프리미엄 사용자는 광고 SDK 를 시작하지 않으므로 광고를 위한 정보가 전송되지 않습니다.

### 결제 (Google Play)

프리미엄(광고 제거 + 모든 필터) 구매는 Google Play 결제로 처리됩니다.
카드 번호 등 결제 정보는 Google 이 처리하며 Lenumori 운영자는 받지 않습니다.
앱은 프리미엄을 샀는지 확인하기 위해 Google Play 에 구매 내역(구매 여부, 구매 확인 정보)을 조회하며,
그 결과(프리미엄 여부)만 기기 안에 저장합니다.

향후 클라우드 동기화, 외부 AI, 분석 SDK 등의 기능이 추가될 경우
본 개인정보처리방침과 Google Play Data safety 정보를 해당 기능에 맞게 변경합니다.

## 4. 로컬 저장 정보

앱은 기능 제공을 위해 사용자의 기기 내부에 다음 정보를 저장할 수 있습니다.

- 사진·영상 파일 또는 URI
- 사진·영상 촬영 날짜, 영상 길이
- 사용한 필터와 필터 강도
- 필터별 강도·즐겨찾기·최근 사용 기록
- AI 생성 태그
- AI 사진 설명 (영어 원문, 앱 언어가 한국어이면 한국어 번역)
- 사용자가 직접 추가한 태그
- 즐겨찾기 여부
- 앱 설정 (셔터음, 화면 모드, 언어 등)
- 보상형 광고로 연 필터와 사용할 수 있는 시각
- 프리미엄 구매 여부 (Google Play 에서 확인한 결과)

해당 정보는 앱 기능 제공을 위해 사용됩니다.

## 5. 위치 정보

Lenumori MVP는 사용자의 위치 정보를 수집하거나 서버로 전송하지 않습니다.

향후 GPS 기반 장소 태그 기능이 추가되는 경우,
위치 정보 사용 목적과 처리 방법을 사전에 명확히 안내하고 필요한 권한을 요청합니다.

## 6. 계정 및 회원가입

현재 Lenumori는 필수 회원가입 기능을 제공하지 않습니다.

따라서 이름, 이메일 주소, 비밀번호와 같은 계정 정보를 Lenumori 운영자가 수집하지 않습니다.

향후 계정 기능이 추가될 경우 본 개인정보처리방침을 변경하고,
관련 데이터의 수집 목적, 보관 기간 및 삭제 방법을 안내합니다.

## 7. 제3자 SDK 및 오픈소스 라이브러리

Lenumori는 앱 기능 구현을 위해 오픈소스 라이브러리 또는 제3자 SDK를 사용할 수 있습니다.

각 라이브러리의 라이선스 및 저작권 고지는 앱의
'설정 > 앱 정보 > 오픈소스 라이선스' 또는 관련 고지 문서에서 확인할 수 있도록 제공합니다.

제3자 SDK가 사용자 데이터를 외부로 전송하는 기능을 포함하는 경우,
실제 동작을 확인하여 본 개인정보처리방침 및 Google Play Data safety 항목에 반영합니다.

현재 포함된 제3자 SDK 중 외부 전송이 있는 것:
- Google ML Kit GenAI 이미지 설명, ML Kit 이미지 라벨링, ML Kit 번역 — 위 '3. 외부 서버 전송 > Google ML Kit 사용 통계' 참고
- Google Mobile Ads SDK(AdMob), Google User Messaging Platform(광고 동의) — 위 '3. 외부 서버 전송 > 광고' 참고
- Google Play 결제 라이브러리 — 위 '3. 외부 서버 전송 > 결제' 참고

## 8. 데이터 보관 및 삭제

Lenumori가 생성하는 사진 관련 정보와 태그는 기본적으로 사용자의 기기에 저장됩니다.

촬영한 사진과 영상은 휴대폰 기본 카메라와 같은 사진 폴더(DCIM/Camera)에 저장됩니다.
사진 파일에는 촬영 시각, 기기 모델, 노출 값 같은 촬영 정보(EXIF)가 함께 기록되며, 위치 정보는 기록하지 않습니다.
영상 파일에도 위치 정보는 기록하지 않습니다.

사용자는 앱에서 제공하는 삭제 기능을 통해 사진·영상 또는 관련 태그 정보를 삭제할 수 있습니다.
사진·영상을 삭제하면 휴대폰 갤러리의 파일과 붙어 있던 태그가 함께 삭제되며, 되돌릴 수 없습니다.

앱 삭제 시 앱 전용 저장공간에 저장된 데이터는 Android 시스템 정책에 따라 함께 삭제될 수 있습니다.
공용 사진 저장공간에 저장한 사진·영상은 앱 삭제 후에도 남아 있을 수 있습니다.

## 9. 어린이 개인정보

Lenumori는 어린이의 개인정보를 의도적으로 수집하는 것을 목적으로 하지 않습니다.
Lenumori는 어린이를 주 대상으로 하는 앱이 아니며, 광고 역시 어린이를 대상으로 하지 않습니다.

향후 앱의 대상 연령 또는 기능이 변경되는 경우 관련 Google Play 정책을 검토하고 필요한 조치를 적용합니다.

## 10. 개인정보 보호

Lenumori는 불필요한 권한 요청과 외부 데이터 전송을 최소화하는 것을 기본 설계 원칙으로 합니다.

기기 내부에서 처리할 수 있는 정보는 가능한 한 기기 내부에서 처리합니다.

## 11. 개인정보처리방침 변경

앱의 기능, 사용 SDK 또는 데이터 처리 방식이 변경될 경우
본 개인정보처리방침도 변경될 수 있습니다.

중요한 변경이 있는 경우 앱 또는 배포 페이지 등을 통해 안내할 수 있습니다.
